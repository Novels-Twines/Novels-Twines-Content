# Artwork assets

Place approved, optimized cover images and illustrations in this directory structure:

- `covers/` — novel and ColorNovel cover images.
- `illustrations/` — approved episode artwork.

Use descriptive lowercase filenames. Prefer optimized WebP or JPEG for photographs and PNG or SVG for suitable illustrations. Do not commit large source files; use an approved object-storage service when needed.

Only add artwork that the uploader has the right to publish. Do not upload private, sensitive, or unlicensed material.
